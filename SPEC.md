# SPEC.md

## Goal

Write comprehensive static web based user documentation on `Pokemon Emerald Rogue` (a rom hack) using the Git source code.

## Technical Requirements

- End output must be a static web application which can be deployed via Github Pages.

## Functional Requirements

- Overview of core gameplay loop.
- Overview of all quests.
- Overview of game configuration options (e.g. Rainbow mode, Fast Path mode, game difficulty options, etc). 
- Explanation for unique game mechanics in `Emerald Rogue`.
  - How the main hub works.
  - How Safari Zone works (e.g. what criteria for a catch Pokemon to become available to catch via Safari Zone, how to catch legendaries in the hub, etc).
  - How the different routes work (e.g. what the naming of the routes mean, what different route types are available, etc).
  - Any other mechanics which you find based on the source code.
- UX must be modern and easy to use, with a pleasing aesthetic that would appeal to gamers.

## References

- The git source for `pokeemerald-rogue` available in the `references` directory must be the primary reference for all documentation.
